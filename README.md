# 0914_personal-page

A modern, responsive personal website and live real-time clock.

## 🌐 Live Demo

👉 **[View Live Demo on GitHub Pages](https://meimei1000103-dotcom.github.io/0914_personal-page/)**

---

## ✨ Features

- **Personal Profile**: Modern glassmorphic profile card with avatar and skill tags.
- **Live Real-Time Clock**: Real-time digital clock with seconds, date, day of year, and timezone indicator.
- **Interactive Controls**:
  - 12-Hour / 24-Hour format switcher
  - Dark / Light mode toggle (with localStorage persistence)
  - One-click page sharing with toast alert
- **Responsive & Modern UI**: Ambient glowing light orbs, CSS variables, and fluid typography.

## 🛠️ Tech Stack

- **HTML5** (Semantic structure)
- **CSS3** (Glassmorphism, animations, custom properties)
- **JavaScript** (Vanilla JS for live clock & interactions)
- **GitHub Pages** (Continuous deployment)
